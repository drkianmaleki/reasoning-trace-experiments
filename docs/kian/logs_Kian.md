path 3 - Explore the shuffled-resampling idea. A new idea, inspired after realizing that a temporal ordering and a localized jump do not exist: a TOY MODEL, in the physicist's sense of the word — an effective description built to reproduce the measured behavior, with no claim about what the language model actually does internally, and no claim that it "thinks." (Careful with the word "model" here: below, "toy model" means my simulation; "the LM" means the language model under study.) The toy model: each analysis STATEMENT (not sentence) goes into a box, and each statement carries a weight. The output of the box is the answer: an answer is drawn at random according to what is in the box; then the next statement is added (along with the previous result), each with its own weight, and a new draw is made. At some point the box is so packed that adding a statement no longer alters the draw — yet statements keep being added and the same answer keeps being drawn. Fitting the observed curves would require the early statements to carry higher weights than statements added at later stages (a primacy weighting). The toy model is judged the way effective models are judged in physics: by whether it reproduces the measured answer-distribution dynamics and makes a testable prediction — here, that answer distributions should be far more sensitive to rearranging EARLY statements than late ones. That prediction can be tested by SHUFFLED RESAMPLING: permute the first few statements of a prefix and resample. One design caveat for later — shuffled prefixes are off-distribution text the LM never produced, so results would need the same care as any off-policy intervention.

###  path 10 - define block of reasoning and find the nodes based on the blocks rather than sentences. 
I the previous run, it was observed that the model have gradually changes its mind through some sentences. In this phase, we want to ignore the gratual change and focus on the block structure. The reason is as follow, the block structure should help us map out the thinking process of the model and the gradual change only happens within a node. Considering the fact that the narrrated text is not exactly the thinking process, I assume that the natterted may not be the exactly the same within a block but the order of the blocks should be close to the actual thinking process.

The approach to the problem is as follow, I pick a narrated thinking and use LLM as a judge (let's call it LJ) to break it down into blocks. The we feed back the block of the thinking process to the model. then we use LJ to see what were the blocks that happened next and with what probability and the next blocks and so one. This should help us map the thinking process of the model.
