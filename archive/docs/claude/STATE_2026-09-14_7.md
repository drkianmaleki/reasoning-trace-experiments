- Design definitions agreed 2026-09-14 (evening), formal text in 2026-09-14_labeling_scheme_v3.md Section 0e (confirmed):
  - a_T = the source trace's own final answer. P_m = P(answer = a_T | cut(B_m)), cut(B_m) = the prefix ending with the last sentence of block B_m; blocks numbered from 0 like the node subscripts; cut-0 = the empty prefix stays the baseline. Δ_m = P_m − P_{m−1} (Δ_0 against cut-0), signed, no absolute values.
  - Trivial block: Δ_m = 0 (trivial for the answer only; still active in the transition tree).
  - Stopping rule: resample cuts in order; at the first cut with P̂_m = 1 (all n continuations end in a_T) set M and stop; later blocks are trivial by assumption, not measurement. Binomial facts: at n = 25, P̂ = 1 bounds the true P only at 0.887 (one-sided 95%); 25/25 occurs with probability 0.28 at true P = 0.95 and 0.07 at 0.90. Consequence accepted by Kian: no resampled transitions after M (tail transitions from P_corpus and P_source); the E-arm may stop at its first or second cut. At the candidate n = 40: P̂ = 1 bounds the true P at 0.928; 40/40 occurs with probability 0.13 at true P = 0.95 and 0.015 at 0.90.
  - Unresolved continuations ("?") stay in the denominator of P̂, which is always n (frozen-run convention; decided by Kian); their count is reported per cut; one "?" prevents the stop, so the rule is conservative.
  - Tk(x) = token count of x (block, node, cluster of blocks, chain of nodes) in the studied model's own tokenizer, from one tokenization of the whole trace, tokens assigned to blocks by character offset, spans partitioning the trace so Σ Tk(B_m) = Tk(trace). The unit of localization.
  - Stage one reports, all descriptive and without thresholds: P_m and Δ_m with intervals; the block with the largest Δ_m and its Tk next to Tk(trace); the gap between the largest and second-largest Δ_m; the plot of Δ_m against m. "Localized" and "diffuse" are readings, not verdicts.
  - Two stages: stage one at every block-end cut under the stopping rule is the registered run; stage two, optional, node-level cuts inside the single block with the largest Δ_m, decided after the stage-one plot, budget permitting, registered separately. Near-tie rule (decided): if the 95% interval of the gap Δ_(1) − Δ_(2) excludes zero, the top block alone, otherwise both; at n = 40 the gap's standard error is up to about 0.16, so gaps below roughly 0.3 count as ties; a fraction of the average Δ_m was rejected as reference because the Δ_m telescope to P_M − P(a_T | cut-0).
