# reasoning-trace-experiments

**Work in progress** — active working repository continuing
[decided-mid-thought](https://github.com/drkianmaleki/decided-mid-thought),
a MATS 12.0 submission studying where a reasoning model commits to its
answer within its chain of thought. That repo is the finished project as
submitted; this one holds ongoing and future experiments.

## Layout
- `archive/decided-mid-thought/` — frozen copy of the original project files
- `runs/experiments/` — full-scale experiment runs
- `runs/scratch/` — tests and short exploratory runs
- `prompts/` — question/option inputs consumed by scripts
- `figures/` — plots and summary outputs
- `docs/kian/` — Kian's logs · `docs/claude/` — Claude's state files ·
  `docs/shared/` — confirmed summaries of methods and findings
